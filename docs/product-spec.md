# product-spec.md — 念念 AI 视频工作台（sd2.cauai.fun）

> 版本：v0.1（基于 2026-09-17 审计重写，先还原事实，再定义范围）
> 状态：待 老大 确认

---

## 1. 这个产品是什么

一个面向**短剧 / 漫剧内容生产者**的 AI 视频生成工作台：上传人物、关键资产、场景与可选视频/音频参考，填写提示词，选择渠道档位，创建并跟踪生成任务，最后下载成品。

**它不是**：模型提供方、视频剪辑软件、发布平台。

---

## 2. 用户是谁（当前事实推导）

- 当前注册用户 4 个，均通过邮箱 OTP 登录。
- 真实任务形态：`i2v` 为主（20 条历史任务中 14 条 i2v），提示词为**长篇导演级描述**（含分镜、光色、动作、台词、地图规范），单条提示词可达数千字。
- 结论：用户是**专业内容生产者**，不是尝鲜玩家。产品必须服务"长提示词 + 多素材 + 连续镜头"的重度场景。

## 3. 要解决的问题

1. 把"写长提示词 + 管素材 + 下单 + 等结果 + 下载"收敛到一个工作台，而不是在渠道网页里手工操作。
2. 用积分把不透明的渠道点数变成可控成本。
3. 保留历史任务与素材，支持复用与微调再投。

## 4. 核心用户流程（必须可验证）

```
登录（邮箱 OTP）
  → 进入工作台（三栏：素材库 / 提示词与投放区 / 任务状态）
  → 选择模式（文生视频 t2v / 图生视频 i2v / 文生图 t2i）
  → 选择档位（省钱 / 均衡 / 高质量 / 长时长 / 图片）
  → 投放素材（按渠道 assetLimits 校验数量与类型）
  → 填写提示词（长度校验）
  → 下单（积分预扣 → 提交渠道 → 返回任务 ID）
  → 轮询状态（排队 / 处理中 / 完成 / 失败）
  → 完成：预览 + 下载（落 COS 签名 URL）
  → 失败：展示渠道原因 + 一键复用参数重试
```

## 5. 明确不做（Out of scope）

- ❌ 自研/自训练模型。
- ❌ 多渠道比价路由（MVP 只有紫域，其它渠道未配置）。
- ❌ 视频剪辑、时间线编辑、配音合成（当前无对应可用渠道）。
- ❌ 一键发布到第三方平台（不存在该能力）。
- ❌ 开放自助注册（MVP 邀请制）。
- ❌ 移动端优先适配（MVP 桌面端三栏为基线）。

## 6. 失败场景与处理（必须实现）

| 失败场景 | 用户看到什么 | 系统做什么 |
|---|---|---|
| 未登录 / 会话过期 | 跳转登录，登录后回到原页面 | 401 → 前端统一拦截 |
| 积分不足 | "本次需要 X 积分，当前余额 Y，前往充值" | 前端预校验 + 服务端二次校验 |
| 模型失效 | "所选档位已下线，已切换为 XX" | 回退 activeModelId 并提示 |
| 提示词为空 / 超长 | 明确字数限制提示 | 前后端双校验 |
| 素材数量/类型不符 | "当前渠道最多添加 N 个图片" | 依据 model.assetLimits 校验 |
| 内容审核未通过 | "内容审核未通过，请修改提示词或素材" + 保留参数重试 | 记录原因，不自动重试 |
| 渠道系统异常 | "渠道暂时异常，正在重试" | 自动重试 1 次，仍失败则退款 |
| 网络/超时 | "任务状态获取失败，可手动刷新" | 状态轮询带退避，不判定失败 |

## 7. 验收标准（可测试）

- AC-1：已登录用户能在 3 次点击内完成一次 i2v 下单。
- AC-2：下单后任务在任务区可见，状态随渠道真实状态更新（不早于渠道返回判定成功）。
- AC-3：积分在下单时冻结，终态后结算；失败按 `docs/channels-and-models.md` D3 退款。
- AC-4：任一档位失效时，系统自动回退并可继续下单，用户可见提示。
- AC-5：所有生成结果可下载，链接有效期 ≥ 24h。
- AC-6：刷新页面后，任务列表与素材库状态保持（真实持久化）。
- AC-7：核心链路在移动端窄屏下不崩溃（可降级，但不可白屏）。

## 8. 待确认事项（阻塞开工）

1. 积分对外定价与紫域点数汇率。
2. "内容审核未通过"是否扣费（影响退款规则）。
3. 是否开放注册 / 邀请制白名单来源。
4. 是否需要多用户协作与权限分级。
