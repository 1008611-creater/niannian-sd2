# ADR-0004：源码入 Git，服务器不再是真相源，发布可回滚

- **日期**：2026-09-17
- **状态**：提议（待确认）
- **背景**：
  - 部署目录 `/srv/kidswear-data/staging/niannian-sd2-4998bd8` **无 `.git`**。
  - `.github/workflows/ci.yml` 存在但只做 typecheck + build，且因无仓库**从未运行**。
  - 镜像 `niannian-sd2:957e1ff` 构建于 2026-08-16，已 32 天未重建，与线上源码存在漂移风险。
- **决策**：
  1. 源码以本仓库为唯一真相源；服务器目录只作为部署产物。
  2. `main` 受保护：禁止直推；PR 必经 CI（`.github/workflows/ci.yml` 升级版）+ 至少 1 人 review；L3 变更双人 review。
  3. 每次发布保留上一可用镜像 tag 与迁移回滚脚本，发布后执行核心链路冒烟并记录。
  4. 部署流程从"手工改服务器文件"改为"仓库构建 → 镜像 → 部署"。
- **后果**：
  - 正面：可回滚、可审计、CI 真正生效。
  - 负面：需要一次性整理当前服务器目录（含历史 POST_CODING_REVIEW_*.md 等文件）并入仓，工作量不小。
