# ADR-0003：积分预扣 + 终态结算 + 分类退款

- **日期**：2026-09-17
- **状态**：提议（**待 老大 确认汇率与审核失败是否扣费**）
- **背景**：
  - 紫域以"点数"计价：图片 5~20 点，视频 50~2000 点；失败任务中标注"未扣费"的 cost 显示为 0。
  - 但"内容审核未通过"的任务 cost 仍显示 300，**是否真实扣费未知**。
  - 当前 `credit_ledger` 仅 1 条记录，说明计费链路基本未走通。
- **决策**：
  1. 汇率：1 紫域点 = 1 积分；对外展示倍率由 `CREDIT_EXCHANGE_RATE` 配置（默认 1.0）。
  2. 下单即冻结积分，任务到达终态后结算；中途取消/异常按失败处理。
  3. 分类退款：
     - `任务提交失败，未扣费`（模型失效、参数错误）→ 全额解冻，不扣积分，自动回退模型后允许重试
     - `系统异常` → 自动重试 1 次，仍失败则全额退还
     - `内容审核未通过` → **确认前按不退款处理，并在 UI 明示**；确认后按紫域实际扣费对齐
  4. 每次扣费/退款写入 `credit_ledger`，字段含 `provider_job_id`、`provider_cost`、前后余额、原因码。
- **后果**：
  - 正面：账目可审计；用户成本可预期。
  - 负面：审核失败不退款可能引发争议，需在 UI 显著提示并考虑赠送重试券。
