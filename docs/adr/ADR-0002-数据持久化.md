# ADR-0002：Postgres 为唯一数据源，遗留 SQLite 迁移后归档

- **日期**：2026-09-17
- **状态**：提议（待确认）
- **背景**：
  - Postgres 容器 healthy，但 `public` schema **0 张表**；`deploy/migrations/` 两个迁移文件从未执行。
  - 应用容器内只有 `POSTGRES_USER`/`POSTGRES_PASSWORD`，**缺少 `POSTGRES_DB`**。
  - 磁盘上遗留 `/app/data/niannian-auth.sqlite`（372KB，最后写入 2026-08-23），含 `users=4 / sessions=5 / user_credits=4 / credit_ledger=1 / projects=1 / uploaded_assets=2`；当前镜像 node_modules 只有 `pg`，无 sqlite 驱动。
  - `.env.production` 为 CRLF 且首行被污染为 `nnvlwyufbemejgjfPOSTGRES_DB=...`，是 `POSTGRES_DB` 丢失的直接原因。
- **决策**：
  1. 单一数据源 = Postgres。SQLite 仅作为迁移来源，迁移完成后归档至 `_archive/`，代码中不得保留业务引用。
  2. 迁移文件版本化在 `deploy/migrations/`，部署流程强制执行并校验。
  3. `.env.production` 统一 LF，增加键名完整性校验脚本，缺失即部署失败。
  4. 生产库每日 `pg_dump` 备份，季度演练恢复。
  5. 新增 `provider_jobs` 表，作为渠道任务对账真相表。
- **后果**：
  - 正面：账目、任务、素材可审计可恢复；消除双真相源。
  - 负面：迁移窗口需停机或双写校验；需双人 review 与回滚脚本。
