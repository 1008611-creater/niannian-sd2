# Image2 / Seedance2 经验沉淀循环

本文件用于把用户在多个 Codex 线程里做 Image2 出图、首帧资产和 Seedance2 视频生成时遇到的问题、修复办法和最终规则沉淀回 `ai-video-fundamentals-skill`。

优先级：这些实战问题和解法是本技能最重要的增量来源。维护 AI 视频技能时，优先从它们和本地 Obsidian vault `D:\codex-work\aaa\ai视频创作知识库` 提炼规则。

## 何时使用

读本文件，当任务涉及：

- 总结或复盘 Image2 / Seedance2 失败案例。
- 从旧线程、素材、提示词、截图、视频结果中提炼经验。
- 更新 AI 视频冠军 skill。
- 诊断为什么图、首帧、视频、镜头、角色、产品、动作、声音或后期不稳定。
- 把一次解决办法变成可复用规则、模板或检查清单。

## 信息来源优先级

1. 用户明确指出的旧线程、当前线程、失败记录、成功结果和人工判断。
2. 本地 Obsidian vault：`D:\codex-work\aaa\ai视频创作知识库`。
3. 当前 `ai-video-fundamentals-skill` 的 references 和校验脚本。
4. 项目里的素材、提示词、脚本、视频输出和发布记录。
5. 外部教程或网页资料。外部资料只能补充，不能覆盖用户实战结论。

## 单条经验卡格式

每条可沉淀经验必须写成这种结构：

```text
标题：
场景：Image2 / 首帧 / Seedance2 / 后期 / 发布 / 其他
目标：
失败现象：
错误做法：
根因判断：
有效修复：
可复用规则：
适用边界：
验证证据：
应该更新到：
```

字段要求：

- `失败现象` 写观众或创作者实际看到的问题，不写空泛判断。
- `根因判断` 要落到资产、提示词、首帧、参考图说明、镜头、动作、声音、抽卡、剪辑或发布环节。
- `有效修复` 写具体动作，例如改首帧构图、减少资产负担、补参考图说明、拆动作阶段、改光线方向、后期镜像、换字幕策略。
- `可复用规则` 必须能指导下一次生产。
- `适用边界` 写清什么时候不能套用。
- `验证证据` 可以是文件路径、截图、视频片段、线程名、用户确认或复测结果。
- `应该更新到` 在 `SKILL.md`、`prompt-templates.md`、`checklists.md`、`video-types.md`、`vault-extraction.md`、`mx-shell-case-rules.md` 或新 reference 中选一个。

## 沉淀流程

1. 先收集失败前后的完整链路：目标、输入图、提示词、参考图说明、首帧、生成参数、输出结果、用户判断。
2. 把问题归入一个主环节，不要把所有失败都归咎于模型。
3. 找到最小有效修复：能改提示词就不重做人设；必须改首帧时不要继续抽卡浪费次数。
4. 判断是否值得写进 skill：
   - 一次性项目细节，写进项目文档或 Obsidian。
   - 会反复影响 Image2 / Seedance2 质量的规则，写进本 skill references。
   - 涉及工具/API/平台操作的步骤，写进对应执行 skill。
5. 更新对应 reference 后，运行 `scripts/validate_ai_video_plan.py` 或相关校验；没有可运行计划时至少人工检查三段式、资产、首帧、抽卡、后期和诊断门。
6. 保留短记录：问题、修复、更新位置和验证证据。

## 经验归类

优先把经验放入这些桶：

- `角色一致性`：脸、发型、服装、道具、行为锚点。
- `产品稳定性`：产品形状、Logo、材质、使用方式、可变/不可变部分。
- `首帧控制`：构图、身份、空间关系、光线方向、动作起点。
- `参考图说明`：每张图的主体、用途、不要改变的部分。
- `Seedance2 动作`：阶段拆解、速度、受力、入画出画、镜头运动。
- `抽卡挑片`：整条可用、局部可用、重跑、改首帧、改提示词、改分镜。
- `后期修复`：动作匹配、速度、镜像、调色、字幕层级、声音。
- `发布平台`：封面、标题、字幕密度、平台原生感和转化目标。

已沉淀的第一批用户实战经验卡见 `references/image2-seedance2-lessons.md`。后续从旧线程或项目中提炼出的高频失败模式，应优先追加到该文件；如果某条规则已经稳定复用，再同步压缩进 `SKILL.md`、`checklists.md` 或 `prompt-templates.md`。

## 路由规则

- Image2 只是生成图或首帧时，如果它服务于视频、角色、产品、叙事或 Seedance2，先用 `ai-video-fundamentals-skill` 做质量判断，再叠加具体 Image2 渠道 skill。
- Seedance2 只是执行渠道时，可叠加 `seedance2-*` 或 `echoon-*` skill；但提示词、镜头、抽卡和诊断的主判断仍归本技能。
- 当旧线程经验和外部教程冲突时，优先保留用户实战验证过的结论。
- 不把失败案例原样堆进 `SKILL.md`。`SKILL.md` 只保留高频规则；具体案例放 reference 或 Obsidian。
