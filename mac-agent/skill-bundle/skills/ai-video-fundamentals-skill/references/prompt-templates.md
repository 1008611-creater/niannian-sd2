## Image2 多模块角色圣经图模板

用于主要角色、固定 IP、剧情短片主角、系列人物、需要进入 Seedance2 的角色参考图。不要只做单张全身正面照。

先用文生图跑出真实人物效果和审美方向，再用图生图打磨细节。不要在 T2I 阶段写太多会诱导概念设定图的词，例如“电影美术组”“character bible”“海报级”“史诗电影感”“世界观场景”。人物参考第一轮更适合写成真实试装照、选角参考照、普通摄影棚白底、自然皮肤、无电影调色、无海报摆拍。

给 Image2 的模型 prompt 正文不要写“用途：”段，也不要单独写“限制：”段。用途写在文件名、任务记录或对话说明里；限制项融入 `【氛围与画质】` 和 `【画面内容】` 的自然描述中。

```text
【基础设定】
角色姓名：
角色类型：
世界观：
不可改变的身份锚点：
禁止项：

【氛围与画质】
风格核心：真实服装试装 contact sheet / 选角参考照 / 普通摄影棚白底人物档案，不是概念设定图，不是海报，不是杂志写真。
画幅：16:9 横版，一张图内包含多个清晰模块。
材质与光线：自然皮肤纹理、普通软箱灯、无电影调色、无强氛围光、衣服真实旧但不过度造型化。
限制词：无随机文字、水印、Logo、乱码；不要游戏角色板、不要游戏 CG 感、不要 Unreal Engine 渲染、不要 3D render、不要 CGI、不要游戏预告片质感、不要概念艺术、不要过度锐化、不要塑料皮肤、不要把多个模块画成不同角色。

【画面内容】
同一角色的多模块参考板，所有模块必须是同一个人：
1. 正面全身：展示完整服装搭配、身高比例、主色块。
2. 侧背轮廓：展示远景可识别轮廓、外套长度、背影特征。
3. 脸部近景：展示眉眼、脸型、年龄气质、发型轮廓。
4. 服装材质细节：展示领口、袖口、外套、围裙/医疗包/手套等关键搭配。
5. 道具细节：展示角色常用道具，必须和身份绑定。
6. 关键动作姿态：展示角色最常出现的行为习惯。
7. 镜头暴露点：明确远景、中景、近景分别应该露出的识别信号。
```

## 氛围画质词库

### Image2 默认干净质感后缀

用于 Image2 资产图、场景图、首帧图和需要高质感的故事板图。默认追加在 Image2 prompt 末尾，除非用户明确要求粗粝胶片、脏污质感、纪录片颗粒、故障艺术或低保真风格。

```text
超高细节，徕卡画质，保持所有元素材质；smooth shading, soft lighting, controlled details, minimal texture, high clarity, refined edges, smooth gradients --- no noise, grain, artifacts, high frequency detail, dirty texture, oversharpen, blotchy, chaotic details.
```

使用要点：

- 正向部分用于保留真实材质和干净边缘，不要只依赖负向词压噪。
- 对暗黑、夜景、古堡、车祸、VFX 等复杂画面，优先减少画面元素和纹理密度，再追加此后缀。
- 如果画面仍然乱，先退回单一主视觉、单一机位、少人物、无文字、无拼板，不要继续堆更多细节词。

真实感增强：

- 超写实
- 极致逼真
- 真人实景拍摄
- 真实摄影动态模糊
- 胶片颗粒
- 自然日光
- 高光不过曝
- 暗部保留细节

限制词：

- 杜绝游戏 CG 感
- 杜绝动作僵硬
- 杜绝廉价 AI 质感
- 不要过度锐化
- 不要塑料质感

摄影语言：

- IMAX 胶片摄影机
- Panavision C 系列镜头
- 手持跟拍
- 固定机位
- 高空俯拍
- 轻微仰拍
- 推拉摇移

## Seedance2 多参考图职责模板

用于 Echoon / Seedance2 支持多图参考并可用 `@图片名` 调用的模型。不要只上传多张图后写“参考这些图片”。

```text
参考图上传顺序：
@first：true first frame，控制视频第一帧构图、人物与产品的起始接触关系、空间和光线。
@person：只控制人物身份、脸、发型、服装、手套、鞋子和身体比例；不控制背景。
@product_lock：只控制商品结构、颜色、材质、Logo 位置、轮子/配件和不可变形态。
@scene_lock：只控制车库/厨房/户外等场景、光线和空间关系；不控制人物身份。
@composition_ref：只控制姿势、机位、产品尺度或动作方向；不要复制这张图里的人脸、发型、衣服或错误道具。

提示词写法：
Use @first as exact first frame. Use @person only for identity and outfit. Use @product_lock as exact product reference. Use @scene_lock for background and lighting. Use @composition_ref only for pose, camera angle, action direction, and product scale; do not copy the person from it.

动作前引用：
0-1s: With @first as the starting frame, the presenter grips the product with exactly two hands...

禁止：
不要让构图参考控制身份；不要让身份参考改产品；不要上传没有明确职责的装饰参考；不要超过当前模型允许的图片数量。
```

## 发布版口播与 TTS 音色克隆模板
