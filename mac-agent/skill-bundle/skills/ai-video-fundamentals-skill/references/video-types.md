# AI 视频类型参考

## 类型矩阵

| 类型 | 核心目标 | 提示词重点 | 后期重点 |
|---|---|---|---|
| 剧情短片 | 讲故事、制造情绪 | 角色、动机、关系、情绪递进 | 连续性、节奏、情绪停顿 |
| 产品广告 | 建立欲望、展示卖点 | 产品资产、商业摄影、卖点可视化 | 产品定格、品牌字幕、调色 |
| 电商带货 | 信任、转化 | 真实使用、痛点证明、行动理由 | 快节奏、字幕、价格/规格信息 |
| 人物口播 | 建立人设、传递信息 | 脸、口型、眼神、背景、声音 | 字幕、剪停顿、B-roll |
| MV/情绪片 | 情绪、节奏、视觉记忆 | 母题、色彩、光影、节拍 | 音乐卡点、重复视觉符号 |
| 知识教程 | 解释清楚 | 信息结构、步骤、字幕留白 | 图示、字幕、节奏 |
| 纪录片/伪纪录片 | 现场感、可信度 | 观察感、自然光、同期声 | 粗粝感、环境声、少量字幕 |
| 游戏动画 | 世界观、角色动作 | 风格规则、动作逻辑、技能展示 | 音效、节奏、UI 后期添加 |
| 动作/VFX | 速度、冲击、奇观 | 空间、受力、阶段、运镜 | 动作匹配、加速、光效、调色 |

## 类型判断问题

1. 观众看完要做什么：理解、购买、关注、共情、转发，还是记住一个世界？
2. 视频靠什么成立：人物、产品、信息、情绪、动作，还是奇观？
3. 失败时最不能坏的是什么：脸、产品、动作、字幕、光线、节奏，还是品牌调性？

## 类型化输出

### 剧情短片

- 先写人物关系和动机。
- 每个镜头只承担一个叙事任务。
- 不要靠字幕解释关键剧情。

### 产品广告

- 先做产品资产卡。
- 产品外形、颜色、Logo、材质不能漂。
- 画面必须证明卖点。

### 电商带货

- 第一秒给痛点或产品。
- 多写真实使用动作和手部互动。
- 字幕服务购买决策。

### 人物口播

- 镜头克制，脸和声音优先。
- 手势少而准。
- 复杂 B-roll 后期插入。

### MV/情绪片

- 先定义主情绪、主色、视觉母题。
- 镜头和音乐节拍匹配。
- 避免随机漂亮素材堆叠。

### 知识教程

- 一个镜头一个知识点。
- 构图留字幕和图示空间。
- 复杂文字后期加。

### 纪录片/伪纪录片

- 自然光、同期声、观察感。
- 少用过度完美的广告构图。
- 人物不要总看镜头。

### 游戏动画

- 明确渲染风格和动作规则。
- UI 和文字尽量后期加。
- 角色轮廓比脸更重要。

### 动作/VFX

- 写清空间、受力、入画、出画和结果。
- 高速镜头不要锁死全部构图。
- 生成后按动作方向和镜头方向剪。
