# 从 Obsidian `ai视频创作知识库` 提炼的核心规则

来源 vault：`D:\codex-work\aaa\ai视频创作知识库`。

## 知识库结构

- `00-入口`：通用 AI 视频创作体系，强调目标、类型、三段提示词、资产、生成、后期、评估。
- `01-视频拆解`：Mx-Shell《丧尸清道夫》创作思路总览。
- `02-提示词方法`：基础设定、氛围与画质、画面内容与分镜头、可复用模板。
- `03-案例库`：丧尸清道夫的基础设定、氛围画质、追逐分镜、抽卡、后期经验。
- `04-工作流`：资产卡、单镜头、多分镜生成工作流。
- `05-后期剪辑`：动作匹配、速度、字幕层级、光线方向、调色。
- `06-类型库`：剧情、产品、电商、口播、MV、知识、纪录片、游戏动画、动作/VFX。
- `07-镜头语言库`：镜头任务、剪辑节奏、信息型分镜。
- `08-资产与一致性`：角色一致性、产品资产、声音字幕。
- `09-生产体系`：目标到发布的全流程生产线。
- `10-评估与诊断`：按类型和问题定位修正动作。

## 总流程

```text
目标与类型
-> 创意和脚本/内容目标
-> 三段式提示词
-> 资产卡
-> 静帧/首帧
-> 视频生成
-> 挑片与诊断
-> 重跑或修正
-> 后期剪辑
-> 调色、声音、字幕
-> 发布版本
```

关键：这是循环，不是一次写完就一路生成。生成结果可以反向修正提示词、资产、首帧、镜头和剪辑。

## 常见误区

- 把提示词写成一句图片描述。
- 只写电影感、真实感、高级感，不拆摄影、镜头、光线、色彩和限制。
- 上传参考图但不解释参考图主体。
- 用字幕解释剧情，而不是让画面动作和空间关系成立。
- 过度制作不重要资产，增加模型负担。
- 复杂动态镜头锁死所有细节，导致动作僵硬。
- 只看完整片段是否可用，忽略局部入场、转身、爆点可剪价值。
- 后期不检查动作方向、镜头方向、光线方向和空间关系。

## 诊断映射

| 问题 | 优先修正 |
|---|---|
| 主体变形 | 资产卡 / 首帧 |
| 风格跑偏 | 氛围与画质 |
| 动作不对 | 画面内容 / 阶段拆解 |
| 镜头乱 | 景别 / 构图 / 运镜 |
| 剪不起来 | 动作方向 / 光线方向 / 后期策略 |
| 信息看不懂 | 分镜结构 / 字幕 / 构图 |
