# AI 视频基本功检查清单

## 故事检查

- [ ] 是否先拆解了观看者真正想看的部分，而不是直接把脚本逐句翻译成画面？
- [ ] 是否明确了爆点 / 记忆点 / 最容易被复述的内容？
- [ ] 是否明确了信任证据：观众凭什么相信这不是空话？
- [ ] 是否列出了画面优先级：哪些必须重点拍，哪些只做辅助？
- [ ] 是否列出了不该重点拍的内容，避免视频变散、变假、变宣传片？
- [ ] 用户是否已经确认爆点方向？未确认前不能进入人物图、信息图、首帧图、故事板或视频提示词生产。
- [ ] 一句话钩子是否成立？
- [ ] 主角目标是否清楚？
- [ ] 阻力/冲突是否具体？
- [ ] 是否不是旧爆款换皮或泛泛的酷风格？
- [ ] 世界规则是否能通过服装、道具、空间、光线或动作被看见？
- [ ] 关键物件是否有现实原型，观众不读设定也能一秒说出用途？
- [ ] 是否存在孤立神秘物件、游戏任务物品或靠新名词解释的道具？如果有，先换成现实物件。
- [ ] 每个镜头是否由上一个动作导致？
- [ ] 爽点或情绪点是否能被画面看懂？
- [ ] 是否有一个观众能记住的画面或物件？
- [ ] 是否需要字幕解释才成立？如果需要，退回重写故事。

## 类型检查

- [ ] 是否明确视频类型？
- [ ] 是否明确观众看完要做什么？
- [ ] 是否明确不可失败项？
- [ ] 是否按类型选择了镜头节奏？
- [ ] 是否避免把所有类型都写成“电影感大片”？

## 提示词检查

- [ ] 是否分为基础设定、氛围与画质、画面内容？
- [ ] 是否解释了参考图中每个主体是什么？
- [ ] 是否写了声音限制？
- [ ] 是否写了正向风格核心？
- [ ] 是否写了反向限制词？
- [ ] 是否写了景别、构图、运镜和画面动作？
- [ ] 是否写了动作原因，而不只是动作表面？

## 资产卡检查

- [ ] 主角是否有稳定身份锚点？
- [ ] 主要角色是否已通过辨识度五件套：脸部结构、发型轮廓、服装搭配、常用道具、行为姿态？
- [ ] 人物参考图是否是多模块角色圣经图，而不是单张全身正面照？
- [ ] 是否先用 T2I 跑出真实人物效果、审美方向、服装搭配和辨识度，再考虑 I2I 细节打磨？
- [ ] T2I prompt 是否避免“电影美术组、概念设定图、史诗电影感、游戏角色板、海报摆拍”等会降低真实感的词？
- [ ] T2I 是否明确排除游戏 CG 感、Unreal Engine 渲染、3D render、CGI 和游戏预告片质感？
- [ ] 人物资产是否像真实演员试装/选角参考，而不是游戏角色、影视概念图或高精渲染模型？
- [ ] 如果 T2I 不真实或不够好看，是否继续打磨 T2I，而不是拿弱图进入 I2I？
- [ ] 每个角色是否写清远景、中景、近景分别要暴露哪些识别点？
- [ ] 如果人物图偏弱，是否已停止继续 i2i，改为重做人设而不是锁定弱参考？
- [ ] 产品是否有外形、材质、颜色、Logo、不可变区域？
- [ ] 电商产品是否锁定了完整商品身份，而不是泛化品类名？
- [ ] 产品卡是否写明常见误变体，例如不要变成其他型号、其他工具或散装配件？
- [ ] 工具/设备类商品是否写清接触点、受力关系、线缆/开关/配件和使用动作？
- [ ] 场景是否表达世界观？
- [ ] 场景是否包含空间边界、入口出口、主体位置、动作方向、爆点前状态和光线方向？
- [ ] 道具是否影响动作逻辑？
- [ ] 关键道具是否和人物动作同框，而不是孤立摆拍？
- [ ] 表情是否需要跨镜头保持？
- [ ] 如果人物只是为商品操作服务，是否优先用手部、袖子、手套、半身等局部人体锚点降低身份漂移？
- [ ] 是否过度制作了不重要素材？
- [ ] 自动生成资产是否太卡通、太塑料、太偏离风格？

## 首帧检查

- [ ] 首帧是否是最终视频的正确画幅比例？
- [ ] 主体或关键道具是否能在一秒内读懂？
- [ ] 身份锚点、关键道具、空间关系和光线方向是否清楚？
- [ ] 首帧是否是真视频起点，而不是海报、概念图或静态成片？
- [ ] 首帧是否给主体动作、镜头运动和 Seedance2 延展留下空间？
- [ ] 角色识别点是否在首帧实际暴露，而不是只存在于角色设定里？
- [ ] 电商首帧是否包含完整产品、真实使用场景、操作者逻辑和准确动作起点？
- [ ] 带人商品首帧是否产品主导，而不是人物写真或擦边构图抢戏？
- [ ] 商品功能片是否锁住接触点，例如支撑点、螺母、气嘴、线缆、开关或握持位置？
- [ ] 人物拿商品/工具时，手数、手臂连接、接触点、受力方向和产品支撑是否清楚？
- [ ] 大件工具 presenter 镜头是否优先使用双手或身体贴近支撑，避免单手悬空感？
- [ ] 钻入、滑入、推入、拉出类动作是否写清头脚方向、目标物位置、发力部位和镜头跟随对象？
- [ ] 是否没有意外文字、水印、UI、错误 Logo 或乱码？
- [ ] 构图是否给动作留下空间，而不是死板海报？

## 镜头单元检查

- [ ] 镜头是否按转场/剪点/机位断点划分，而不是按 5 秒生成任务划分？
- [ ] 这个镜头是否只有一个叙事任务？
- [ ] 是否只有一个主情绪或主动作？
- [ ] 是否只有一个摄影策略？
- [ ] 是否写清声音规则？
- [ ] 是否写清通过条件和失败条件？

## 生成检查

- [ ] 单镜头是否准备多版抽卡？
- [ ] 关键 Seedance2 proof shot 是否按候选池执行，而不是一条定成败？
- [ ] 每条候选是否标注：整条可用 / 局部可用 / 需重跑 / 需改首帧 / 需改提示词？
- [ ] 是否下载并保留 1-2 秒局部可用片段，如入场、抬眼、动作爆点、道具亮相？
- [ ] 多分镜是否有阶段、时间、景别、运镜和关键结果？
- [ ] 8s/10s 或更长连续镜头是否拆成多个 5s 技术子段，并明确它们仍属于同一个长镜头？
- [ ] 是否抽取上一段尾帧？
- [ ] 下一段首帧是否明确来自上一段尾帧？
- [ ] 尾帧是否能承接人物、道具、空间、光线和动作？
- [ ] 是否避免把 SD2 技术子段写成剪辑分镜或可见转场？
- [ ] 独立电商 6 秒 proof clip 是否避免默认尾帧接龙，改用每条完整 Image2 首帧？
- [ ] Seedance2 电商 proof 是否只接简单运动提示，而不是把产品、动作、口播和后期全部塞进同一个生成任务？
- [ ] 多参考图是否给每张图命名，并在提示词中用 `@图片名` 明确身份、产品、场景、构图或动作职责？
- [ ] 旧生成图如果只作构图参考，是否明确禁止复制旧人物、旧服装或旧产品错误？
- [ ] Echoon / Seedance2 本地命令超时后，是否先查 `task.json` 和已有 `task_id`，而不是重复提交？
- [ ] RH / RunningHub i2i 是否使用公网可访问 reference URL，并在付费前 dry-run 检查 `imageUrls`、画幅、分辨率和 prompt？
- [ ] 平台安全审核拒绝时，是否先改构图、人物占比和商品主导关系，而不是盲目重传同一张首帧？
- [ ] 是否避免用图片慢推或 PPT 拼接冒充视频镜头？
- [ ] 高速运动镜头是否过度锁死构图？
- [ ] 是否保留了模型合理发挥空间？
- [ ] 是否区分“整条可用”和“局部可用”？
- [ ] 失败后是否先诊断变量，而不是盲目重 roll？
- [ ] 同一失败重复两次时，是否退回故事、首帧或镜头设计？

## 后期检查

- [ ] 动作方向是否能接上？
- [ ] 镜头运动方向是否一致？
- [ ] 光线方向是否连续？
- [ ] 影子方向是否合理？
- [ ] 主体身份是否稳定？
- [ ] 速度感是否足够？
- [ ] 字幕是否遮挡主体？
- [ ] 色温、色调、饱和度是否统一？
- [ ] 是否需要柔光、发光或轻微滤镜增强氛围？
- [ ] 多段电商 proof 是否先输出总成半成品和联络图给用户确认方向，再进入深度 QC 或局部重跑？

## 声音与音色一致性检查

- [ ] 是否区分 proof 版 SD2 同期音轨和发布版口播音轨？
- [ ] 有口播、数字人、商业带货或固定人设时，是否准备授权音色样本或已有 voice id？
- [ ] 是否用同一个 TTS 克隆音色生成全片口播，而不是多个随机音色拼接？
- [ ] 口播是否按中文短视频断句，有钩子、重音、停顿和行动理由？
- [ ] TTS 克隆口播是否与画面动作、字幕和剪辑点对齐？
- [ ] 电商发布版 VO 是否后期统一生成，SD2 音频只保留 SFX、工具声、空间底噪或 room tone？
- [ ] 是否保留少量 SD2 现场环境声、手部动作声和空间底噪？
- [ ] 环境声是否 ducking 到不抢口播，口播不炸、不闷、不忽大忽小？
- [ ] 跨镜头是否没有音色、口音、音量、情绪和空间感突变？
- [ ] 是否避免克隆未授权真人声音？

## 类型化质量检查

- 剧情短片：角色动机和情绪是否读得懂？
- 产品广告：产品是否稳定，卖点是否可见？
- 电商带货：产品是否被锁定为可购买商品，使用动作是否物理可信，首帧是否产品主导，行动理由是否清楚，发布版口播音色是否一致？
- 口播：脸、口型、克隆音色、字幕是否同步可信？
- MV/情绪片：视觉母题和音乐节奏是否统一？
- 知识教程：一个镜头是否只讲一个知识点？
- 纪录片：是否有观察感和现场感？
- 游戏动画：风格规则和角色动作是否稳定？
- 动作/VFX：空间、受力和剪辑方向是否连贯？

## 常见问题

### 画面 AI 味重

补充真实拍摄语言：摄影机、镜头、光线、胶片颗粒、动态模糊、色彩影调和限制词。

### 角色不稳定

减少无关资产，强化主角身份锚点；必要时做表情卡、服装卡或道具卡。

### 动作僵硬

写动作原因、身体受力、环境互动；不要只写“奔跑、攻击、摔倒”。

### 镜头不好看

补景别、构图和运镜；动态镜头不要把每个细节锁死。

### 多段剪不起来

优先匹配镜头运动方向、人物动作方向、光线方向和空间关系。

### 用图片当视频 / PPT 式成片

正片叙事镜头必须是真视频运动。图片只能作为资产、首帧、参考图或非叙事说明卡，不能用静帧慢推、图片拼接或文字卡补剧情来冒充成片。
