## 经验卡 1：人物参考图不是单张全身正面照

标题：人物参考图必须做成多模块角色圣经图  
场景：Image2 / 首帧 / Seedance2  
目标：让观众在视频镜头里稳定认出角色，而不是只在静态立绘里觉得人物好看。  
失败现象：人物图只是漂亮全身照，脸、发型、服装搭配、道具和行为姿态都不够独特；进入视频后变成普通写实人物。  
错误做法：继续用单张正面全身图当角色参考，或在弱人物图上反复 i2i 微调。  
根因判断：角色识别系统没有建立，镜头可暴露的识别点不足。  
有效修复：重新文生图做多模块角色圣经图，一张图内包含正面全身、侧背轮廓、脸部近景、服装材质细节、道具细节、关键动作姿态和镜头暴露点。  
可复用规则：角色参考图至少包含 `脸部特征 / 发型轮廓 / 全身搭配 / 侧背轮廓 / 道具 / 行为姿态 / 镜头暴露点`，不能只是一张全身正面照。  
适用边界：一次性背景群众、不可跨镜头识别的路人不需要角色圣经图。  
验证证据：用户在主线程指出“人物参考图不只是一个全身正面照，包含的内容是很多的，最好一次性文生图做出来”；随后项目切到 `rh-round4-character-bibles`。  
应该更新到：`prompt-templates.md`、`checklists.md`。

## 经验卡 2：角色辨识度靠五件套和镜头暴露

标题：观众只能认出镜头里实际暴露的识别信号  
场景：Image2 / 首帧 / Seedance2 / 剪辑  
目标：让角色跨镜头可识别。  
失败现象：角色图片单看还行，但视频里观众认不出 Holmes、Watson、Clay；人物变成普通黑衣侦探、普通医生或普通工人。  
错误做法：只写“保持角色一致”，或者只靠一件衣服、一个道具识别人物。  
根因判断：缺少脸/发型、服装搭配、道具/行为三类互相支撑的识别系统。  
有效修复：把角色设计拆成五件套：脸部结构、发型轮廓、服装搭配、常用道具、行为姿态；每个镜头必须暴露至少 2 个关键识别点。  
可复用规则：远景靠轮廓、服装色块和手持物；中景靠穿搭组合和行为习惯；近景靠脸部结构、发型和眼神。识别点没被拍到，就等于没有设计。  
适用边界：蒙面、头盔、屏幕脸角色可以把脸部项替换成面具/头盔/屏幕图形，但仍需服装、道具和行为锚点。  
验证证据：`101_V6当前制作锁定卡_红章招工.md` 已写入“角色识别硬规则”；`102_首轮Image2资产验收页_V6_红章招工.md` 已写入“辨识度五件套”。  
应该更新到：`SKILL.md`、`checklists.md`。

## 经验卡 3：弱人物图不要继续 i2i，先重做人设

标题：弱参考会把后续图和视频全部拖进泛化  
场景：Image2  
目标：避免把不够出色、不够一致的第一批人物图当成后续参考。  
失败现象：第二轮人物图有进步但仍然缺脸部辨识度和服装搭配差异；继续往下做首帧会把问题带进 Seedance2。  
错误做法：为了省时间把“候选偏弱”的人物图继续作为 i2i 参考。  
根因判断：参考图本身没有建立角色系统，i2i 只能稳定弱点，不能自动补齐角色设计。  
有效修复：停止继续出图，旧人物图降级或删除；重新用文生图设计角色圣经图。  
可复用规则：当人物图没有通过辨识度五件套时，不进入首帧，不进入 Seedance2，不做 i2i 锁定迭代。  
适用边界：如果只是局部材质或小道具不稳，可修提示词或 i2i；如果脸、发型、搭配、道具、姿态整体弱，必须重设。  
验证证据：主线程用户要求“重新设计，不需要用之前的图参考，之前的人物图删了就行”；项目随后清理旧 H01/W01/C01 人物卡。  
应该更新到：`learning-loop.md`、`checklists.md`。

## 经验卡 4：首帧是真视频起点，不是海报

标题：Image2 首帧必须能接 Seedance2 运动  
场景：Image2 / 首帧 / Seedance2  
目标：让首帧锁住主体、空间、光线和动作起点。  
失败现象：首帧像海报或概念图，画面漂亮但不能自然开始运动；动作空间不足，Seedance2 只能漂移或乱动。  
错误做法：把首帧当最终静态成片，追求摆拍、全信息展示或封面感。  
根因判断：没有区分资产图、动作关系图、true first frame 和发布封面。  
有效修复：首帧只做剧情现场第一帧，必须包含人物/产品动作起点、空间关系、光线方向、镜头运动余量和关键识别点。  
可复用规则：白底资产解决身份，动作关系图解决空间/行为，true first frame 解决 Seedance2 起点；三者不能混用。  
适用边界：纯海报、封面、角色设定页不需要能接运动，但不能拿它们直接生成叙事镜头。  
验证证据：`00_先看这里.md` 写入“首帧控制：F00 / F02 / F04 只做视频起点，不做海报，不做静态成片”。  
应该更新到：`checklists.md`、`prompt-templates.md`。

## 经验卡 5：动作关系图比单人立绘更能推进剧情

标题：有叙事任务的资产优先于孤立角色卡  
场景：Image2 / 首帧  
目标：让 Image2 资产服务镜头因果和 Seedance2 动作逻辑。  
失败现象：单人白底图能看，但剧情不成立；镜头里看不出人物在做什么、在哪里、会造成什么后果。  
错误做法：先做大量单人图、道具图、风格图，再临时拼成镜头。  
根因判断：资产没有绑定现实动作和空间关系。  
有效修复：关键资产优先做动作关系图，例如 `Clay 柜台边低身搬箱`、`Holmes 白手套拈灰观察 Clay`、`药库墙破等待关系图`。  
可复用规则：所有关键资产必须能回答“谁在做什么、发生在什么空间、这个动作会造成什么后果”。  
适用边界：主角身份锚点仍需要白底/角色圣经图，但进入首帧前必须补动作关系图。  
验证证据：`102_首轮Image2资产验收页_V6_红章招工.md` 结论：“单人白底图只能解决身份锚点，真正让剧情成立的是动作关系图”。  
应该更新到：`checklists.md`。

## 经验卡 6：场景图要服务 Seedance2，不只是气氛好

标题：场景细节必须包含空间动线和可运动关系  
场景：Image2 / 首帧 / Seedance2  
目标：让场景能承接人物动作、镜头运动和后期剪辑。  
失败现象：场景图氛围对，但细节不足、空间不清，或墙洞太大、人物太暗、传统侦探表皮干扰一致性。  
错误做法：只要求“电影感药库”“末世旧货铺”，没有定义动线、墙体状态、人物位置和可见动作。  
根因判断：场景图没有为 Seedance2 的动作和镜头留清晰起点。  
有效修复：把场景图写成空间/关系锚点：旧货铺柜台与地下室门动线、药库配给装车关系、药库墙破前一秒等待关系。  
可复用规则：场景图必须明确 `空间边界 / 入口出口 / 主体位置 / 动作方向 / 爆点前状态 / 光线方向`。  
适用边界：纯背景氛围图可弱化动线，但不能作为剧情首帧或动作镜头参考。  
验证证据：R07B 洞太大、R07C/R07D 帽子/传统侦探表皮风险，被验收页判定“不直接进 F04”。  
应该更新到：`checklists.md`、`prompt-templates.md`。

## 经验卡 7：Seedance2 proof shot 是素材池，不是一次成败

标题：关键 proof shot 默认多版抽卡并分类挑片  
场景：Seedance2 / 后期  
目标：把生成结果变成可剪素材，而不是要求每条一次完整完美。  
失败现象：只跑一条 proof shot，失败就以为方向错；或只看整条可用，忽略局部好片段。  
错误做法：把 `P01 / P02 / P00` 理解成只生成三条视频。  
根因判断：没有按素材池思维评估 Seedance2 输出。  
有效修复：关键任务默认多版：P01/P02 至少 4 个候选，P00 至少 3 个候选；每条标注整条可用、局部可用、需重跑、需改首帧、需改提示词。  
可复用规则：入场、抬眼、墙砖松动、点灯、配给车灯亮这类 1-2 秒局部可用片段也要下载保留。  
适用边界：极低风险的简单 B-roll 可少跑，但关键剧情镜头不能只跑一版。  
验证证据：`101_V6当前制作锁定卡_红章招工.md` 的“抽卡与挑片规则”。  
应该更新到：`checklists.md`、`prompt-templates.md`。

## 经验卡 8：同一失败重复两次必须回退变量

标题：不要硬 roll 已经诊断出的错误  
场景：Image2 / Seedance2 / 后期  
目标：降低生成浪费，避免把错误锁进后续流程。  
失败现象：主体变形、风格跑偏、动作不对、镜头剪不起来时继续盲目重跑。  
错误做法：把所有失败都当成“再抽一次可能好”。  
根因判断：没有把失败映射回资产、首帧、氛围、画面内容或后期策略。  
有效修复：同一失败重复两次时回退：主体变形改资产或首帧；风格跑偏改氛围与画质；动作不对改画面内容；剪不起来改动作方向或后期策略。  
可复用规则：重跑前先判断变量；必须改首帧时不要继续消耗 Seedance2。  
适用边界：模型偶发小瑕疵可继续抽卡；结构性失败必须回退。  
验证证据：`00_先看这里.md` 和 `101_V6当前制作锁定卡_红章招工.md` 都写入诊断迭代规则。  
应该更新到：`checklists.md`。

## 经验卡 9：文字、Logo、编号和全息标注全部后期添加

标题：不要让 Image2 / Seedance2 生成关键可读文字  
场景：Image2 / Seedance2 / 后期  
目标：避免乱码、错字、水印、伪 Logo 破坏可信度。

错误做法：把关键说明、编号、招工纸文字、药库标签交给模型直接生成。  
根因判断：生成模型在文字细节上不稳定，且会破坏可控性和后期修改空间。  
有效修复：画面里只保留纸张、标签、屏幕、全息区域的物理位置；文字、编号、UI、字幕后期添加。  
可复用规则：Image2 / Seedance2 提示词必须写“无随机文字、水印、Logo、乱码；所有文字后期添加”。  
适用边界：不可读的远景纹理可存在，但不能承担叙事信息。  
验证证据：`101_V6当前制作锁定卡_红章招工.md` 的“声音与后期锁定”。

## 经验卡 10：声音分 proof 和发布版

标题：Seedance2 同期声只作 proof，发布版统一 voice id  
场景：Seedance2 / 后期 / 发布  
目标：保持角色音色、口播和环境声统一。  
失败现象：不同镜头声音、口音、音量、空间感不一致；随机台词污染发布版。  
错误做法：直接把 Seedance2 随机同期声当发布版。  
根因判断：生成同期声适合判断现场感和节奏，不适合承担固定角色音色。  
有效修复：proof 阶段保留环境声；发布版旁白和台词统一后期 TTS / voice id，只保留少量现场底噪和动作声。  
可复用规则：固定人设、口播、剧情对白和商业带货发布版，都必须有音色统一策略。  
适用边界：无对白、纯环境情绪片可保留更多同期声。  
验证证据：`38_角色一致性圣经_福尔摩斯与华生.md`、`101_V6当前制作锁定卡_红章招工.md` 均写入发布版统一 TTS / voice id。

## 经验卡 11：工具渠道不能覆盖质量方法

标题：Image2 / RH / Echoon / Seedance2 skill 只补执行，不抢冠军判断  
场景：技能路由 / Image2 / Seedance2  
目标：避免可用工具链把视频质量判断带偏。  
失败现象：某个作图或平台代理 skill 失效、误导或绕过冠军方法；比如 API key disabled 的渠道继续留在路由里。  
错误做法：因为工具会生成，就让它主导创作决策。  
根因判断：渠道能力和质量方法混在一起。  
有效修复：删除失效渠道，保留 RH / Echoon / Seedance2 等执行 skill，但入口规则必须先过 `ai-video-fundamentals-skill`。  
可复用规则：方法层判断“该做什么、为什么这样做、怎样验收”；渠道层只负责“怎么提交、下载、批量执行”。  
适用边界：纯技术排障可直接用渠道 skill，但回到成片质量时必须走冠军 skill。  
验证证据：线程 `019eb87d-643e-7a82-b72a-3ce85263ba76` 已删除冲突 skill，并给核心链路补“基本功优先”；主线程删除 `beecode-image2` 后切 RH。  
应该更新到：`skill-governance`、`SKILL.md`。

## 经验卡 13：电商视频先锁产品，不锁就会变成泛化道具

标题：产品锁定比“商业质感”更优先  
场景：Image2 / 首帧 / Seedance2 / 电商视频  
目标：让观众看到的始终是同一个可购买产品，而不是类似品类道具。  
失败现象：电动千斤顶变成普通剪式千斤顶、手动卧式千斤顶、散装气泵、无线电钻或一堆不成套工具。  
错误做法：只写“car jack kit”“roadside tool kit”或“high quality product ad”，没有锁定外形、颜色、结构、配件和不可变项。  
根因判断：产品资产卡不足，模型按品类常识补全，导致商品身份漂移。  
有效修复：先写产品资产卡，锁定橙色 VEVOR 电动液压千斤顶、黑色顶托和底座、12V 线、黑色硬箱、橙色电动冲击扳手、充气泵压力表、套筒、手套和线缆；同时写明不能变成哪些常见替代物。  
可复用规则：电商视频的产品卡必须包含 `产品名 / 品类 / 外形比例 / 主色 / 材质 / 关键结构 / 配件 / 不可变项 / 常见误变体 / 使用动作`。产品身份失败时先改产品卡和首帧，不继续抽视频。  
适用边界：非商品类氛围片可以弱化产品锁定；只要视频目标是带货或广告，产品锁定就是第一优先级。  
验证证据：`script_01\plan.md` 的 Non-Negotiables 和 Product Asset Card；`scripts_02_08_batch_plan.md` 的 Product Lock。  
应该更新到：`checklists.md`、`prompt-templates.md`。

## 经验卡 14：短电商 proof clip 不要默认尾帧接龙

标题：独立 6 秒商品证明片用完整首帧，不用尾帧串联  
场景：Image2 / 首帧 / Seedance2 / 电商视频  
目标：每个短 clip 都能独立证明一个卖点，并能被后期自由重排。  
失败现象：尾帧接龙把上一条的构图、错误产品形态或动作残留传给下一条，导致产品展示不完整、剪辑不灵活。  
错误做法：把所有 Seedance2 任务都按剧情长镜头逻辑，用上一段尾帧硬接下一段首帧。  
根因判断：没有区分连续叙事长镜头和独立电商 proof clip。  
有效修复：每条 6 秒竖屏短片都从完整 Image2 首帧开始，首帧同时包含产品、车辆/使用场景、操作者手部或身体逻辑、准确动作起点；Seedance2 只接简单运动提示。  
可复用规则：电商短视频的独立卖点证明片默认 `一条 clip = 一个完整首帧 + 一个简单动作`；只有连续空间、连续动作、连续机位真的需要保留时才用尾帧接龙。  
适用边界：剧情片、长镜头、连续动作段仍可用尾帧接首帧；独立商品卖点 clip 不默认接龙。  
验证证据：`scripts_02_08_batch_plan.md` 明确“No tail-frame chaining”和“Every clip starts from a complete Image2 first frame”。  
应该更新到：`checklists.md`、`prompt-templates.md`。

## 经验卡 15：商品钩子可以有人，但画面必须产品主导

标题：电商 presenter hook 不能被人物抢戏  
场景：Image2 / 首帧 / Seedance2 / 电商视频 / 平台审核  
目标：让真人/手部提供信任和使用场景，同时让产品和动作成为第一视觉主体。  
失败现象：首帧人物太像写真或擦边广告，平台安全审核拒绝；或者人物好看但产品变成陪衬，钩子不卖货。  
错误做法：用 glamour-coded 构图、把人物放大到压过产品，或只追求“吸睛”而没有商品证明。

适用边界：纯达人口播可让人物主导，但商品广告首帧仍要在 1 秒内看见产品和使用理由。  
验证证据：`hook_qc_report.md` 记录早期 S01 首帧因“too glamour-coded”被 Echoon safety review 拒绝，替换为 product-dominant professional roadside composition 后通过。

场景：Image2 / RunningHub / 首帧

## 经验卡 17：电商动作必须物理可信，不只是“看起来在用”

标题：商品功能证明要锁接触点和受力关系  
场景：Image2 / 首帧 / Seedance2 / 电商视频  
目标：让产品卖点通过真实动作被观众相信。  
失败现象：车身像悬浮、千斤顶没有顶在支撑点、冲击扳手没有对准螺母、充气管没有接气嘴、LED 变成无关手电。  
错误做法：只写“jack lifts the car”“impact wrench works fast”“inflator is visible”，不写接触点、使用位置、动作限制和失败条件。  
根因判断：动作证明缺少物理约束，Seedance2 会用泛化动作填空。  
有效修复：首帧先锁定支撑点、轮胎、线缆、开关、套筒、气嘴、压力表、LED 照射区域等可见关系；视频提示词只让动作小幅发生，避免整车夸张升起或工具漂移。  
可复用规则：商品功能片必须写 `产品接触哪里 / 谁在操作 / 动作幅度 / 哪个结果可见 / 哪些危险或夸张动作禁止`。  
适用边界：纯外观展示可弱化受力关系；任何使用证明、对比演示、维修/工具类商品都必须锁物理关系。  
验证证据：`script_01\plan.md` 的 Non-Negotiables：wheel lift physically plausible、impact wrench contacts lug nuts、inflator hose connects to tire valve。  
应该更新到：`checklists.md`、`prompt-templates.md`。

## 经验卡 19：真人只为商品服务时，优先用局部身体降低身份漂移

## 经验卡 20：三只手、悬空产品这类问题要先修首帧，不靠视频提示词硬补

标题：手数和受力关系是首帧闸门  
场景：Image2 / 首帧 / Seedance2 / 电商工具视频  
目标：让人物拿产品、推产品、坐产品、躺产品这些动作在第一帧就物理可信。  
失败现象：修车躺板 S01 出现三只手、独立黑手、断手或产品靠一只手悬空；进入 Seedance2 后错误被放大，变成多手、产品掉落感或手臂连接不自然。  
错误做法：首帧已经有多余手或支撑点不清，却继续用更强的负面词让视频模型“不要三只手”。  
根因判断：首帧没有通过手数门和接触点门。Seedance2 会继承首帧里的局部错误，并在运动中把模糊手套、边框、阴影解释成新手。  
有效修复：重做 true first frame，减少参考图干扰；把动作改成更稳定的两手分别抓左右侧栏/把手，产品贴近身体受力；首帧先肉眼确认只有两只手、两条手臂自然连接、产品被真实支撑，再提交视频。

适用边界：纯产品 B-roll 或无手部接触镜头可弱化手数门；只要画面中出现手套、袖口、把手、边框等容易被模型解释成手的元素，就必须检查。

## 经验卡 21：用多参考图时必须给每张图命名并在动作前引用

标题：多参考图不是堆图，是角色分工  
场景：Seedance2 / Echoon / 电商视频  
目标：让 Seedance2 明确哪张图锁身份、哪张图锁产品、哪张图锁场景、哪张图只借构图和动作。  
失败现象：多图参考混用时，模型把旧人物复制进新视频、把构图参考的人脸当身份、或把产品参考和首帧姿势互相污染。  
错误做法：上传多张图后只写“参考这些图片”，不说明每张图的职责和禁用范围。  
根因判断：Seedance2 接收到多张视觉证据，但没有被明确告知控制权归属，容易从错误参考里抽取身份、服装、产品形态或动作。  
有效修复：给每张图稳定命名，并在提示词中用 `@图片名` 放在动作和约束前说明职责，例如 `@person` 锁身份和服装，`@product_seat` 锁产品结构，`@product_wheel` 锁轮子细节，`@first` 作为 exact first frame；如果使用旧片段截图作构图参考，必须写“只参考姿势/机位/产品尺度，不复制人物”。  
可复用规则：多参考图提示词必须包含 `参考图上传顺序 / 每张图的控制对象 / 不允许从该图继承的内容 / 动作前 @ 引用`。额外参考图只有能降低身份、产品或动作漂移时才上传。  
适用边界：单张 true first frame 足够控制的简单镜头，不必强行多图；多图越多，职责越要写清，否则会增加污染。  
验证证据：Echoon 页面提示支持“用 @图片名 引用图片并放在动作前”；VEVOR creeper `v11-clean-hands` 使用 `@first/@person/@product_seat/@product_wheel` 重跑 S01，解决三手和产品支撑问题。  
应该更新到：`prompt-templates.md`、Echoon 执行 skill。

## 经验卡 22：第一人称或低机位滑行动作必须锁身体方向和发力来源

标题：滑进车底要写清头脚方向和谁在发力  
场景：Image2 / 首帧 / Seedance2 / 电商工具视频  
目标：让观众相信人物真的躺在修车躺板上，用腿发力滑向车底。  
失败现象：修车躺板 S02 被生成成脚先进入车底，或产品/身体像自己滑动；观众看不懂是头朝车底、腿在后方发力。  
错误做法：只写“slide under the car”或“POV slides under car”，不指定头、脚、车和镜头的相对位置。  
根因判断：低机位和第一人称构图存在方向歧义，模型会按常见脚部入画或镜头漂移动作解释。  
有效修复：首帧明确车在头的方向，腿和脚在后方/前景；提示词写清“head-first toward the car, boots behind, legs push against concrete, camera travels with the body”。如果旧首帧方向错误，不能只改文字，必须换首帧。  
可复用规则：所有滑动、推入、钻入、躺下、拉出类动作都要写 `头脚方向 / 车或目标物位置 / 发力部位 / 身体支撑物 / 镜头跟随对象`。  
适用边界：纯外观滚动或无人产品 B-roll 不需要锁头脚方向；有人使用工具进入狭窄空间时必须锁。  
验证证据：VEVOR creeper `v10-4x4-corrections` 的 S02，首帧和提示词改为头朝车底、腿在后方后，轻量抽帧通过并拼入 `v10/v11` 四段半成品。  
应该更新到：`checklists.md`、`prompt-templates.md`。

## 经验卡 23：先发四条总成半成品，让用户引导方向，再做深度 QC

标题：电商短片先看方向，不要过早陷入局部 QC  
场景：Seedance2 / 后期 / 用户协作  
目标：在多段电商视频中先让用户确认节奏、卖点顺序和大方向，再决定重跑哪一段。  
失败现象：还没给用户看总成节奏，就在单条镜头里做深度 QC 和反复重跑；可能修了局部，却偏离用户想要的整体结构。  
错误做法：每生成一条就做完整审片和细修，迟迟不输出可观看的四段/整条半成品。  
根因判断：电商短视频的成败不只在单镜头质量，还在四段连起来的节奏、钩子、证明链和 CTA。用户反馈往往需要基于总成片判断。  
有效修复：每轮重大调整后先拼接总成半成品，做轻量门槛检查即可：文件能播、顺序正确、明显错误不存在。然后把总成片交给用户，让用户指出方向性问题，再进入深度 QC 或局部重跑。  
可复用规则：`4x4`、`3x6` 等多段电商 proof 结构，优先交付 `总成半成品 + 联络图 + 单条文件`；深度 QC 在用户确认方向后进行。  
适用边界：有安全、版权、明显失败、不可播放问题时必须先拦截；剧情片或竞赛片的导演审片也可能需要更严格的内部 QC 再给用户。  
验证证据：用户在 VEVOR creeper 线程明确要求“做 qc 之前，先把这四条总成完整半成品片发出来”，后续 `v9/v10/v11` 都按四段总成半成品推进。  
应该更新到：`checklists.md`、后期交付规范。

## 经验卡 24：文生图先做效果，图生图只打磨细节

标题：T2I 先定真实效果，I2I 后修细节  
场景：Image2 / 角色资产 / 首帧  
目标：避免把不真实、AI 设定感、概念图感的人物资产继续锁进后续参考链路。  
失败现象：多模块角色圣经结构完整，但人物不够真实，像影视概念设定板、游戏角色板或 AI 选角海报；继续图生图只会让脸、服装和氛围更精致，但不会自然变成真实可拍人物。  
错误做法：T2I 阶段还没跑出真实人物效果，就把弱图拿去 i2i 修脸、修材质、修道具。  
根因判断：把 T2I 和 I2I 的职责混在一起。T2I 应该解决审美方向、真实感、角色辨识、服装组合和人物气质；I2I 只适合在方向正确后做细节收敛和一致性控制。  
有效修复：先打磨文生图提示词，减少“电影美术组、character bible、35mm 电影感、世界观场景”等会诱导概念图的词；改用真实试装照、选角参考、普通摄影棚白底、自然皮肤、无电影调色、无海报摆拍等真实摄影约束。T2I 出现真实可用人物后，再进入 I2I 细修脸部、服装材质、道具位置和多镜头一致性。  
可复用规则：`T2I = 定方向和真实效果；I2I = 打磨已通过方向的细节`。如果 T2I 不真实、不好看或不够辨识，必须继续打磨 T2I prompt，不进入 I2I。  
适用边界：已有高质量真人授权参考、品牌产品实拍图或用户指定参考图时，可以直接进入 I2I；但仍要先判断参考图本身是否通过真实感和识别门。  
验证证据：V6《红章招工》Round5 角色圣经图结构完整但被用户指出“不够真实”；用户明确要求“先打磨提示词，用文生图把效果先做起来，再用图生图打磨细节”。  
应该更新到：`SKILL.md`、`prompt-templates.md`、`checklists.md`。
## 经验卡 25：视频渠道的人物图拦截不是靠白线硬绕

标题：人物首帧被渠道政策拦截时及时换路由
场景：首帧 / Seedance2 / 视频渠道
目标：用已确认人物首帧生成转绘视频，同时避免把渠道政策失败误判成提示词失败。
失败现象：Mimo / NAS Seedance2 对已确认的 `偏心学弟 EP001_SEG001A V01 S001-S005` 首帧返回 `图片中包含人物`；用户授权添加细白线、粗斜白线兼容标记后，仍未产出 MP4。
错误做法：继续反复本地加线、遮挡、打码或改提示词，试图绕过同一个人物图拦截。
根因判断：这是视频渠道的输入政策/风控拦截，不是镜头提示词、时间轴或资产职责没写清；白线兼容标记不能改变“图中包含人物”的通道判断。
有效修复：记录 provider_policy blocker，停止 Mimo 白线重试；保留已确认首帧作为视觉权威，改走能接受人物首帧的真实视频渠道，或在用户明确要求继续 Mimo 时重新生成无人物首帧。
可复用规则：人物首帧被渠道返回 `图片中包含人物` 后，最多只做一次用户明确授权的兼容性验证；同错复现即沉淀为渠道阻塞，不再追加本地修图。
适用边界：只适用于 Mimo/NAS 这类对上传人物首帧有政策拦截的渠道；其他渠道若允许人物首帧，应使用原始已确认首帧，不继承白线版。
