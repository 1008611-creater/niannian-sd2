# Mx-Shell《丧尸清道夫》案例迁移规则

本文件只保留可迁移方法，不复刻丧尸、机器人、鸵鸟、原子朋克题材表皮。

## 基础设定

案例基础设定的价值：

- 机器人清道夫有稳定身份锚点：修长人形、LED 屏幕脸、像素表情、牛仔帽、黑色哑光皮衣、手套、腰带、枪套。
- 鸵鸟承担坐骑和荒诞喜剧性，不只是交通工具。
- 丧尸群体承担危机压力，不要求个体一致，但要求材质和状态统一。
- 场景用 1960 年代美式复古原子朋克废城统一建筑、车辆、道具、服装和色彩。
- 声音明确限制为不需要配乐，只保留同期声，方便后期。

迁移原则：

- 主角要有稳定外形锚点、行为锚点和道具锚点。
- 坐骑、载具、怪物、产品或关键道具必须有叙事功能和性格。
- 世界观要给道具、建筑、色彩、服装、声音统一逻辑。
- 生成前决定声音边界。

## 氛围与画质

不要只写“电影感”。拆成：

```text
风格核心：[年代/世界美学] + [题材类型] + [电影级质感] + [真实拍摄感]
限制词：杜绝游戏 CG 感，杜绝动作僵硬，杜绝廉价 AI 质感
摄影基调：[摄影机] + [镜头] + [动态模糊] + [胶片颗粒]
色彩影调：[主色调] + [对比关系] + [饱和度] + [光线方式] + [高光/暗部策略]
整体氛围：[情绪] + [节奏] + [反差]
```

案例可迁移点：

- 用设备和镜头词给模型真实摄影参照。
- 用低饱和、胶片颗粒、自然日光、高光不过曝、暗部保留细节压住廉价 AI 感。
- 色彩要有明确对比关系，而不是堆漂亮词。

## 追逐镜头结构

案例的三镜头功能链：

1. 大全景：交代空间、道路、追逐关系。道路作为引导线，主体从画面边缘或下方入画。
2. 近景：强化角色状态和反差。背景快速后退，身体、服装、道具受速度影响。
3. 物件特写：补充世界观并转场。物件必须承担信息或剪辑连接。

迁移到任何动作镜头：

- 先建立空间，再强化主体，再用特写补信息或转场。
- 动作要和环境互动，例如脚踩报纸、衣物被风影响、武器碰撞、尘土被带起。
- 写入画方向、跟随对象、机位变化和声音。

## 抽卡与挑片

单镜头强动态必须多跑：

- 同时跑多个版本。
- 下载局部可用片段，不只看整条是否完美。
- 可用片段包括入场、转身、跳跃、爆点、镜头运动、动作节奏。
- 角色动作错但镜头运动好，可作为转场或背景素材。
- 表情不准但打斗节奏好，可裁切、遮挡或后期规避。

失败判断：

- 身份完全变形、动作目的错、连续性严重断裂，重跑或改首帧。
- 子弹、道具数量小错、局部抖动，如果不影响叙事，可后期规避。

## 多分镜

AI 可辅助拆动作，但不能直接照搬。人工必须：

- 补缺失分镜。
- 改时间。
- 删除不需要的慢动作。
- 删除不需要的怪物、道具、敌人。
- 补开头、结尾和动作落点。

高速镜头控制粒度：

- 锁阶段、时间、景别、运镜、关键动作结果。
- 构图和微动作可以放开，让模型生成自然运动。

## 后期

案例后期方法：

- 动作匹配转场：镜头运动方向、人物运动方向、动作节奏、入画出画方向要匹配。
- 速度增强：轻微加速即可增强紧迫感和力量感，不要过度。
- 字幕层级：复制素材、抠主体，把文字放中层，人物压在文字上方。
- 空间与光线：检查太阳方向、影子方向、固定物位置；必要时镜像处理。
- 调色与光效：柔光、发光、高光扩散、滤镜、色温微调要轻，不要把画面调脏。
